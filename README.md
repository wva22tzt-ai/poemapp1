# 뭘 살까? 랜덤 뽑기

중국어 회화 수업용 랜덤 뽑기 페이지입니다. 교과서 본문(태양이의 신발 쇼핑)을 바탕으로, 살 물건·색깔·요청할 크기를 무작위로 뽑아 짝과 대화를 이어 가는 활동에 씁니다.

## 사용 방법

1. **뽑기**를 누르면 물건, 색깔, 크기가 정해집니다.
2. 짝과 역할(태양/점원)을 나눠 본문 대화를 뽑힌 단어로 바꿔 말합니다.
3. **병음·뜻 숨기기**를 누르면 중국어만 보고 말하는 연습을 할 수 있습니다.
4. **본문 대화 보기**를 누르면 뽑힌 단어로 바뀐 대화 4줄을 확인할 수 있습니다.

## 양사

화면에는 양사가 나오지 않고 빈칸（　）으로 표시됩니다. 물건 단어를 보고 알맞은 양사를 직접 넣어 말하는 활동입니다.

## 단어

- 물건: 衣服 옷, 裤子 바지, 铅笔 연필, 鞋 신발, 花 꽃, 伞 우산, 大衣 코트, 运动鞋 운동화, 袜子 양말
- 색깔: 白色, 黑色, 红色, 蓝色, 黄色, 绿色, 粉色, 灰色
- 크기: 大 큰 것, 小 작은 것

본문에 없는 단어가 포함되어 있으니 수업 전에 미리 알려 주세요.
